mobsf installation setup :
terminal : bash
docker pull opensecurity/mobile-security-framework-mobsf

mobsf config setup :
terminal : bash
mkdir -p ~/.mobsf

ls -la

cd ~/.mobsf

nano docker-compose.yml
^ config :
services:
  mobsf:
    image: opensecurity/mobile-security-framework-mobsf
    container_name: mobsf
    ports:
      - "[port]:8000" // adjust to the desired port
    restart: unless-stopped

cat docker-compose.yml

docker compose up -d mobsf
docker compose start mobsf
docker compose restart mobsf
docker compose logs -f mobsf

docker inspect mobsf

docker logs -f mobsf

ls -la

sudo ss -tulpn | grep [port]

mobsf config setup :
web browser : UI
open web browser

click on the url tab

write http://127.0.0.1:[port] // adjust to mobsf setup port

then click sign in
